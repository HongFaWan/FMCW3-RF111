## 打开与编辑

克隆后直接用KiCad 10.0.8打开hardware/fmcw3.kicad_pro。首次打开时使用项目内fp-lib-table和sym-lib-table；所有项目库都用${KIPRJMOD}相对路径。11张原理图及项目配置来自当前RF109；移植后原理图导出的components与nets与源工程一致。

PCB里的已有封装、焊盘、铜层、阻焊与锡膏定义是当前RF109的权威。部分上游封装库由已放置实例恢复，不能批量从库更新封装后直接制造；任何更新都需重新检查每个实例与BOM、CPL和Gerber的一致性。

为精简并移除本机模型路径，PCB删除了164个可选3D展示模型块。去除这些模型块后，其余PCB正文与原RF109严格相同，电气几何没有重绘。未附STEP/WRL模型；2D电路和PCB编辑不依赖这些展示模型。

## 版本与性能边界

本板为一路发射、两路接收，使用HMC430、Artix-7与LTC2292。完整四极化外部模块和天线未集成，不在本BOM中。当前软件适配边界为名义5.0–5.5GHz、至少200µs回扫保护；实际PLL锁定、可用扫频带宽、功率、泄漏、接收饱和及SAR成像仍需实板验证。

本仓库此次只归档电路、制造资料及备料信息，没有打包RTL088、FW100、FPGA生成文件、厂商工具或主机软件。它不是可直接烧录的一键整机包；配套数字工程还存在可移植构建依赖，不能把旧版上游固件直接视为已适配本板。

## 备料与装配状态

当前计划为5块PCB，2块双面贴装、3块裸板。18组寄料两板净72件，当时系统备料193件；193已包含损耗和最低上机差额，不再机械加20%。86组由嘉立创原型号重新匹配，库存和分配情况仍需核实。

采购价格与库存是2026-11-15快照，未刷新到本归档日期、未分配或下单。18组候选页面价小计为2097.3452人民币加8.169美元，不含其余86组、制板贴装、运费及包装等费用。实际批号和工厂接料接受均未确认。

31.6kΩ的BRD25ppm是受控BRC15ppm的备选，U40同型号C190862是供料编号提案，均未写入受控BOM。Z1的20S/20SR/20SR1原厂包装对应已确认，实际两颗小量订货号与剪带、批次仍待确认。先读采购说明再核实商家，不能用候选列表替代已批准BOM。

工厂仍需书面确认叠层/阻抗/板厚、116处指定填孔盖铜与28处开孔、CON2成品槽孔与试插、SMA双面焊接、BGA/QFN/WSON钢网与回流/MSL/检查。历史原生检查为DRC0错误/0未连接，但仍报告1013条DRC警告及199条一致性警告；ERC0错误/6警告、沿用3类忽略配置。本次归档未重新进行全板HFSS、ADS、ERC或DRC验收。
