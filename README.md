## RF110变更

R362/R425/R426从RT0402BRC0731K6L改为Panasonic ERA-2ARB3162X：31.6kΩ与0.1%不变，TCR从15降为10ppm/℃，使用原焊盘几何的专用本地封装名称。U40仍为W25Q128JVPIQ WSON 6×5，只将供料编号改为C190862。

全部元件摆放、焊盘、布线、过孔、铺铜、阻焊、锡膏、层叠和电气连接不变；制造图元与RF109相同。没有采用LO衰减器或电源参数的待验证提案。

## 打开与编辑

克隆后打开hardware/fmcw3.kicad_pro，使用项目内fp-lib-table和sym-lib-table；库路径均为${KIPRJMOD}相对路径。90个硬件文件含实际引用的本地符号/封装；已有PCB实例是装配几何权威，不能批量从库更新封装后直接制造。

为可移植性未附可选STEP/WRL展示模型，本快照继承此前删除的164个PCB模型块及30个库模型块；物理焊盘与铜几何均保留。

## 数量与采购

计划5块PCB：2块双面组装，3块裸板。104组均在2026-11-17找到网页可售来源，其中91组来自嘉立创/立创国内渠道，13组需得捷、贸泽或RFMW正规分销补充；不能说全部已能在淘宝或嘉立创直接买齐。库存未占用，批次、包装、税运与工厂最终接料条件待确认。

三只ERA电阻两板净6颗，主选立创官方得捷CT剪带渠道，正常单价约¥5.659398，六颗约¥33.96，不含另计运费；自营C2090771库存0，不可误当现货。

采购表中1692件是独立匹配参考总备料量，其中16项邮寄参考152件、净54件；旧18项193件仅为历史系统口径。这些均不是RF110工厂最终批准数量，不可相加或再次机械加20%。当前受控BOM始终为两板净866件。

## 使用与放行边界

主板为一路发射、两路接收，HMC430/Artix-7/LTC2292架构；完整四极化外置模块与天线尚未集成，不属于这104组。名义软件边界5.0–5.5GHz、至少200µs回扫保护，实际扫频窗口、功率、泄漏、接收饱和、温升和SAR成像待实板验证。本仓库仅硬件/制造/备料资料，不含RTL088、FW100、FPGA生成文件或完整主机软件，不能用旧上游固件直接替代当前适配。

RF110及独立重跑基线均为DRC0活动错误/0未连线，仍有1013条DRC警告和199条原理图封装筛选警告；ERC0错误/6警告，保留3类原有忽略。电源低温偏压有效容量与瞬态、LO驱动余量、工厂叠层/阻抗和完整射频物理验证尚未闭环。

工厂还需书面确认116处指定填孔盖铜、28处保持开孔、CON2槽公差/试插、SMA双面焊接、BGA/QFN/WSON钢网/回流/MSL与检查。当前文件全部REVIEW_ONLY，不能直接付款排产。
